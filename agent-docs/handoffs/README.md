# 跨会话交接

较大阶段完成、需要更换 Agent 或机器、存在未提交修改或长期后台任务时，写一份 `YYYY-MM-DD-topic.md`。交接是带日期的快照，持续变化的事实仍以 [项目状态](../memory/project-state.md) 和源码为准。

交接应包含：当前用户目标与授权范围、已经完成的结果、分支和未提交文件、已运行验证及未覆盖环境、未完成任务的下一步、仍运行的进程或远端任务、接手必读的文档链接。没有的项目明确写“无”即可。

不要复制完整聊天、凭据、论文全文或个人环境路径。用相对路径、提交与运行 URL 让接手者重新核验。

首份入口：[项目理解与协作资料落地交接](2026-11-20-project-onboarding.md)。
