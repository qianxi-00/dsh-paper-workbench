# 开发计划

新增多步骤开发计划放这里，文件名为 `YYYY-MM-DD-topic.md`。历史计划保留在 [旧计划目录](../../docs/plans/)；涉及旧方案时链接原件，不机械搬迁或复制。

一个计划应写清：

- 状态、日期、请求背景、范围及明确不包含的工作。
- 已确认事实、尚待验证的假设和引用的源码/契约。
- 最小方案、阶段依赖、允许修改的文件范围。
- 各阶段验收、实际验证方式和必要的恢复路径。
- 对应 [任务记录](../tasks/README.md)、影响后续工作的决策和交接入口。

状态采用 `proposed / active / completed / superseded`。计划是工作设想，完成证据归任务记录；取消或替换计划时保留原日期和原因。简单低影响修改不必新建计划。
