# 任务记录

这里保存需要跨会话接续的执行记录。按主题建立 `YYYY-MM-DD-topic.md`，相关子任务放在同一文件；长期未处理项可维护在一个主题 backlog 中。

每条任务至少包含：

| 字段 | 要求 |
| --- | --- |
| ID 与目标 | 使用稳定 ID，描述可验收的结果 |
| 状态 | `todo / in_progress / blocked / done / cancelled` |
| 依据与范围 | 关联用户需求、计划、源码及允许修改的位置 |
| 下一步或阻塞 | 给可执行动作；blocked 写明缺少什么，不能只写“待处理” |
| 验证与交付 | 命令、退出码、跳过原因、文件或远端运行 URL；没有执行就写未验证 |

共享 Team 看板、Todo 或会话内计划是执行工具；本目录记录值得长期保存的结论和接续信息，无需逐条镜像工具事件。完成后将稳定事实更新到 [memory](../memory/)，避免任务文件成为唯一知识来源。
