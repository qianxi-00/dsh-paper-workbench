# v1.2.0 收口记录

## 代码与分支

接手时 `agent/v12-finish` 和 `agent/paper-workflows-v1.2` 均指向 `ed3dd45`，两分支间提交和文件树一致。此前留在工作区的 README、使用指南、PDF 与文档修复继续纳入候选。

本轮补齐 `zhpdf.prepare/pause/resume` 及后台阶段持久化，接入原文页按钮和任务状态轮询。插件加载模型服务后恢复运行中的流程，前端重载后重新观察，成功后在当前论文原文页自动切换。复用既有独立翻译与生成入口，核对 PDF、文档和译文快照。生成使用单飞机制。

云端批处理保存 manifest，默认并发 2，自动重试最多一次，支持暂停、恢复及失败项重试。标注迁移仅接受全文唯一的原文摘录，其他情况保留摘录和旧 revision，笔记中显示需复核。重建入口保留旧文档作为迁移依据。

## 真实文库

只读离线审计覆盖 107 篇。104 篇已有版面结果，共 2218 页，状态为需复核。质量报告仍记录 3835 项 blocking 和 17555 项 informational。

`evals-f1e363` 与 `haltt4llm-1f7fd4` 的来源未通过有效 PDF 检查，需补齐原件。`2611.24932-ce9270` 有本地可读的 12 页文本模型，缺少云端版面及 raw。本轮先备份 SQLite 并通过完整性检查，再通过新批处理入口补跑该篇，首次调用与一次自动重试均遇到服务端 HTTP 400、code 10010、任务提交队列已满。失败状态及次数已写入批次 manifest。

完整审计报告、数据库备份和批次任务状态保存在用户数据目录。库中保存的结果仍有质量问题，需逐页复核。
