# 论文工作台使用指南

## 安装与自检

从 [项目首页](../README.md#安装) 安装并启用插件。宿主需要提供 `webServer`、`tools` 和 `connection.requestRejection(req)`；原生会话需要宿主的会话组件和服务。缺少身份校验时 HTTP 入口不会放行。原生会话不可用时，插件会提示原因，不用自绘聊天代替。见[宿主兼容说明](v8-native-session.md)。

- Node.js 20+。Node.js 22.5 之前没有内置 SQLite，工作台会回退到 JSON。
- PDF 页图和文本提取需要 Python 3.10+ 与 `PyMuPDF`（`import fitz`）。缺失时，在 **设置 → 环境自检** 查看诊断；也可用 `npm run doctor`。
- 安装脚本支持 Bash `--dry-run`、PowerShell `-DryRun` 及指定版本；参数和本地源码挂载见[安装技能](../skills/install-dsh-paper-workbench/SKILL.md)。

## 从检索到精读

1. 在 **在线检索** 搜索关键词、DOI 或 arXiv ID，也可按学科浏览订阅。每批目标 100 条候选，按每页 10 篇浏览；上游不足、去重或部分来源失败时会少于 100 条。打开过的论文可从浏览历史找回，结果列表本身不落盘。
2. 在线导入默认进入 **未分类**。可在文库条目上选择 **移动到分类**，输入新分类或选择已有分类。圆点灰色表示未读、橙黄色表示阅读中、绿色表示已读，不代表识别进度。
3. 在 **对照** 中切换双语、并排、原文或只看译文；划词可独立翻译、复制或批注。目录栏可一键翻译尚未翻译的小节标题。
4. 在 **原文页** 可选中文字，或框选图表/公式并把裁图送入右侧原生会话。右栏的 **完整页** 打开同一条 DSH 会话；收起右栏不停止任务。
5. 在 **笔记** 查看研读笔记和原文标注。可导出 Markdown，也可在启用 Obsidian 后写入卡片。

## 翻译与中文版 PDF

翻译走独立通道，译文保存在工作台，不写进 DSH 聊天。设置中可选模型、目标语言、批次和并发（1–100，默认 10）；遇到限流自动退避。切换论文或离开工作台只摘除当前界面的进度订阅，后台任务可继续；需要停下时用 **暂停翻译**。

在 **原文页 → 中文版**，工作台先检查并补齐缺少的译文。只有排版校验通过才生成并切换，失败会保留原视图和已有文件。公式、图片等不是替换对象。详见[中文版 PDF 契约](v6-zhpdf.md)。

## 设置与数据

| 设置 | 用途 |
| --- | --- |
| 导入方式 | 引用原 PDF 路径或复制到文库；移动了引用文件需要恢复其路径。 |
| 网络 | 系统代理、直连、自定义 HTTP/HTTPS/SOCKS5；设置页可测试 arXiv 和 OpenAlex 连通性。 |
| OCR / 版面 | PaddleOCR Token 仅在设置页填写；扫描识别和云端版面会将 PDF 发送给所选服务。 |
| 存储 | 默认 SQLite 或 JSON，也支持 PostgreSQL、MySQL/MariaDB，可先测连接再迁移。 |
| Obsidian | 可选启用并指定 Vault/知识库位置；关闭后不影响阅读、翻译和本地笔记。 |

默认数据目录是 `~/.dsh/paper-workbench`，可由 `DSH_PAPER_WORKBENCH_DATA` 指定。迁移前导出文库或备份数据目录，并备份外置数据库。版面原始响应和旧 revision 可用于离线重建；“解析已覆盖全部页”不等于识别质量已经人工复核。查看[版面归档契约](v7-quality.md)和[OCR 与断点续跑](v4-layout.md)。

维护时先运行 `npm run library:audit -- --data=<库目录>` 查看只读逐篇报告。加 `--rebuild` 会从已归档响应离线重建，需先停止文库上的并发写入；备份和进度保存在库的 `.library-audit` 下。
